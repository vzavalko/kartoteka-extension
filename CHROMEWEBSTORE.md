# Магазин Chrome — ZAKLADKA

> Обновлено: 2026-09-24 · версия в манифесте 1.8.0 · статус: **не опубликовано**

Всё, что нужно вписать в кабинет разработчика, — здесь, копировать как есть.
Архив для загрузки собирает `./pack.sh` → `dist/zakladka-<версия>.zip`.
Картинки витрины лежат в `store/` (в архив не попадают).

## Как опубликовать в первый раз

1. Зарегистрироваться разработчиком: https://chrome.google.com/webstore/devconsole —
   войти Google-аккаунтом, принять соглашение, оплатить разовый взнос **$5**.
2. «Новый элемент» → загрузить `dist/zakladka-1.8.0.zip` (`./pack.sh` соберёт).
3. Вкладки кабинета заполнить по разделам ниже: «Описание» → «Конфиденциальность»
   → «Распространение».
4. Видимость — **«Не в списке»** (Unlisted): в поиске магазина не будет,
   поставить можно только по прямой ссылке.
5. «Отправить на проверку». Первая проверка — обычно от нескольких часов до
   нескольких дней.
6. Когда опубликуют: скопировать адрес страницы расширения
   (`https://chromewebstore.google.com/detail/zakladka/<id>`) и вписать его в
   `EXT_STORE` в `../zakladka/index.html` — плашка «Расширение устарело» начнёт
   вести людей в магазин.

## Как выпускать обновления

1. Поднять `version` в `manifest.json` — магазин не примет архив с той же или
   меньшей версией, а плашка на странице не заметит обновления.
2. `./pack.sh`
3. Кабинет → расширение → «Пакет» → «Загрузить новый пакет» → «Отправить на
   проверку».
4. После одобрения Chrome у всех обновит расширение сам, обычно в течение
   нескольких часов.
5. Дописать строку в «Историю версий» ниже.

## Описание

**Название**
ZAKLADKA

**Краткое описание** (132 символа максимум — здесь 121; то же стоит в `description` манифеста)
Сохраняет вкладки в папки ZAKLADKA одним кликом, показывает открытые вкладки рядом с папками и узнаёт настоящие названия.

**Подробное описание**
```
ZAKLADKA — папки для ссылок вместо сотни открытых вкладок. Расширение сохраняет вкладки в ваши папки на странице ZAKLADKA и закрывает их, чтобы освободить браузер.

Что умеет:
• Сохранить текущую вкладку одним кликом по значку или сочетанием ⌘⇧S (Ctrl+Shift+S) — в активную папку, в любую другую или в новую, заведённую прямо в окошке.
• Показать открытые вкладки полосой рядом с папками: перетащите вкладку в папку — ссылка сохранится, вкладка закроется. Кнопка «Забрать все» разбирает окно целиком.
• Отметить значок галочкой, если страница уже сохранена, и предупредить о повторе.
• Узнать настоящее название страницы вместо голого адреса — в том числе для роликов YouTube и Vimeo.
• Проверить, какие сохранённые ссылки больше не открываются.
• Открывать ZAKLADKA на новой вкладке — с пустой адресной строкой, как обычно. Можно выключить в настройках.
• Хранить запасную копию ссылок на случай, если данные сайта очистят.
• Светлая и тёмная тема — такая же, как выбрана на странице.

Как пользоваться:
1. Поставьте расширение и закрепите значок на панели.
2. Откройте новую вкладку — там ваша ZAKLADKA.
3. Нажмите значок на любой странице и «Сохранить вкладку». Или откройте полосу вкладок кнопкой с книгой и перетаскивайте вкладки в папки.
4. По желанию: значок → шестерёнка → «узнавать названия по адресу».

Конфиденциальность:
У ZAKLADKA нет сервера и аккаунтов. Ссылки и папки хранятся только в вашем браузере и никуда не отправляются. Никакой аналитики и рекламы. Доступ к сайтам нужен только для названий страниц и проверки ссылок и спрашивается отдельно, галочкой.

Вопросы и пожелания: https://github.com/vzavalko/zakladka-extension/issues
```

## Обоснование разрешений

Вписывать в «Конфиденциальность» → поля по каждому разрешению.

| Разрешение | Тип | Обоснование |
| --- | --- | --- |
| `tabs` | permissions | Чтобы сохранить вкладку, расширению нужны её адрес и заголовок. Этим же разрешением показывается список открытых вкладок на странице ZAKLADKA (пользователь перетаскивает их в папки), закрывается вкладка после сохранения и ставится галочка на значке, если текущая страница уже сохранена. |
| `storage` | permissions | Хранит настройки расширения, список папок пользователя для окошка у значка, ссылки, сохранённые пока страница ZAKLADKA закрыта (передаются ей при следующем открытии), и запасную копию ссылок. Всё остаётся на устройстве. |
| `<all_urls>` | optional_host_permissions | Необязательное, спрашивается отдельной галочкой в настройках. Нужно, чтобы по сохранённому адресу узнать настоящий заголовок страницы и по команде пользователя проверить, открываются ли сохранённые ссылки. Ссылки бывают на любых сайтах, поэтому заранее сузить список доменов нельзя. Запросы идут без cookie, из ответа берётся только заголовок или код ответа. |
| `https://vzavalko.github.io/zakladka/*` | content_scripts | Скрипт-мост работает только на странице самого сервиса ZAKLADKA: передаёт ей сохранённые вкладки и список открытых вкладок и принимает её команды. На другие сайты не встраивается. Второй адрес (`/kartoteka/*`) — прежний адрес того же сервиса. |
| `chrome_url_overrides.newtab` | переопределение страницы | Новая вкладка показывает ZAKLADKA — это и есть место, где лежат сохранённые ссылки. Выключается в настройках расширения, тогда новая вкладка показывает кнопку «Открыть ZAKLADKA». |

**Удалённый код** (вопрос в форме): **нет**. Весь код расширения — в пакете.
Новая вкладка показывает страницу ZAKLADKA во фрейме — это обычная веб-страница,
её скрипты в контексте расширения не выполняются.

## Для проверяющих и на будущее

- Если спросят про новую вкладку во фрейме: это страница самого сервиса на
  GitHub Pages, расширение её не изменяет и чужой код не выполняет.
- После публикации у расширения из магазина будет **другой id**, чем у
  распакованной папки. Страницы это не касается (мост цепляется по адресу), но
  тем, кто переходит с папки, надо удалить старую версию, иначе будут работать
  обе. Ссылки не пропадут — они на странице; запасные копии из старого
  расширения — пропадут, их стоит скачать заранее (шестерёнка → «Скачать»).
