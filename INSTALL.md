# ZAKLADKA — установка расширения

Расширение складывает открытые вкладки в ZAKLADKA: забирает настоящие
заголовки, закрывает вкладки и освобождает память Chrome.

Сам сервис — https://vzavalko.github.io/zakladka/ — работает и без него.
Расширение добавляет три вещи: список открытых вкладок прямо внутри сервиса,
настоящие названия страниц и запасную копию ссылок.

## Установка (2 минуты)

Сначала получите папку с расширением — любым из двух способов.

**Скачать одним файлом:**
https://github.com/vzavalko/zakladka-extension/archive/refs/heads/main.zip —
распакуйте (на Mac достаточно двойного клика).

**Через git** (тогда обновляться будет одной командой):

```bash
cd ~/Documents
git clone https://github.com/vzavalko/zakladka-extension.git
```

Дальше одинаково:

1. Положите папку туда, где она останется навсегда — например, в «Документы».
   **Если папку потом удалить или переместить, расширение отвалится.**
2. Откройте в Chrome адрес: `chrome://extensions`
3. Включите **«Режим разработчика»** — переключатель справа сверху.
4. Нажмите **«Загрузить распакованное расширение»** и выберите эту папку.
5. Chrome спросит про страницу новой вкладки — нажмите **«Оставить изменения»**.
6. Закрепите значок на панели булавкой, чтобы был под рукой.

Готово. Теперь `⌘T` открывает ZAKLADKA вместо пустой страницы.

## Как пользоваться

Главное — **кнопка с книгой** в шапке ZAKLADKA. Она показывает вкладки, открытые
прямо сейчас. Перетащите вкладку в папку: ссылка сохранится, а вкладка в браузере
закроется. Кнопка «Забрать все» убирает разом всё окно.

Остальное:

- **Клик по значку расширения** (или `⌘⇧K`) — сохранить ту вкладку, на которой
  вы сейчас стоите. Кнопка «Сохранить вкладку», ниже — выбор папки (можно
  завести новую прямо там) и галочка «и закрыть вкладку». Название страницы
  можно переписать. Открывать ZAKLADKA для этого не нужно.
- **Тихая точка на значке** — эта страница уже в картотеке.
- **«Забрать все вкладки окна»** внизу окошка — всё окно уедет в папку с
  сегодняшней датой.
- **`⌘⇧S`** — то же самое без окошка: вкладка уходит в активную папку и
  закрывается.

## Один раз включить

Значок расширения → шестерёнка → галочка **«узнавать названия по адресу»**.
Без неё названия будут собираться из самого адреса, и ролик с YouTube
превратится в «YouTube — видео» вместо нормального названия.

## Про данные

ZAKLADKA открывается по адресу https://vzavalko.github.io/zakladka/ — это
просто страница, сервера у неё нет. **Ваши ссылки хранятся только в вашем
браузере** и никуда не отправляются. У каждого своя картотека, чужие ссылки
вы не увидите и свои никому не покажете.

Обратная сторона: если почистить данные браузера, ссылки пропадут. Поэтому
расширение раз в сутки само кладёт копию к себе — забрать её можно там же, в
настройках (шестерёнка → «Скачать»). Копия понадёжнее будет, если время от
времени выгружать ссылки файлом: меню `⋯` → «Выгрузить в JSON».

Удалённые ссылки не пропадают сразу — тридцать дней лежат в корзине,
в том же меню `⋯`.

## Как обновляться

Если ставили через git:

```bash
cd ~/Documents/zakladka-extension
git pull
```

Потом в `chrome://extensions` нажать **«Обновить»** на карточке расширения.
Всё, новая версия работает.

Если ставили из ZIP — скачайте свежий ZIP, замените файлы в той же папке
и так же нажмите «Обновить».

## Если Chrome ругается

При каждом запуске Chrome может показывать «Отключить расширения в режиме
разработчика». Это обычное предупреждение для расширений, поставленных не из
магазина, — просто закройте его.
