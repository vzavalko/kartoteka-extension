# Картотека — установка расширения

Расширение складывает открытые вкладки в Картотеку: забирает настоящие
заголовки, закрывает вкладки и освобождает память Chrome.

## Установка (2 минуты)

Сначала получите папку с расширением — любым из двух способов.

**Через git** (тогда обновляться будет одной командой):

```bash
cd ~/Documents
git clone https://github.com/vzavalko/kartoteka-extension.git
```

**Без git:** откройте https://github.com/vzavalko/kartoteka-extension →
зелёная кнопка **Code** → **Download ZIP** → распакуйте.

Дальше одинаково:

1. Положите папку туда, где она останется навсегда — например, в «Документы».
   **Если папку потом удалить или переместить, расширение отвалится.**
2. Откройте в Chrome адрес: `chrome://extensions`
3. Включите **«Режим разработчика»** — переключатель справа сверху.
4. Нажмите **«Загрузить распакованное расширение»** и выберите эту папку.
5. Chrome спросит про страницу новой вкладки — нажмите **«Оставить изменения»**.
6. Закрепите значок на панели булавкой, чтобы был под рукой.

Готово. Теперь `⌘T` открывает Картотеку вместо пустой страницы.

## Как пользоваться

- **`⌘⇧K`** или клик по значку — список вкладок окна. Снять лишние галочки,
  нажать «Сдать» → вкладки закроются, ссылки окажутся в Картотеке.
- **`⌘⇧S`** — сдать текущую вкладку, не открывая список. Копится счётчик
  на значке, сдать всё разом можно позже.
- **Поле в попапе** — вставить любой адрес, расширение узнает его настоящее
  название.

## Один раз включить

Значок расширения → шестерёнка → галочка **«узнавать названия по адресу»**.
Без неё названия будут собираться из самого адреса, и ролик с YouTube
превратится в «YouTube — видео» вместо нормального названия.

## Про данные

Картотека открывается по адресу https://vzavalko.github.io/kartoteka/ — это
просто страница, сервера у неё нет. **Ваши ссылки хранятся только в вашем
браузере** и никуда не отправляются. У каждого своя картотека, чужие ссылки
вы не увидите и свои никому не покажете.

Обратная сторона: если почистить данные браузера, ссылки пропадут.
Раз в пару недель делайте копию: в Картотеке меню `⋯` → «Выгрузить в JSON».

## Как обновляться

Если ставили через git:

```bash
cd ~/Documents/kartoteka-extension
git pull
```

Потом в `chrome://extensions` нажать **«Обновить»** на карточке расширения.
Всё, новая версия работает.

Если ставили из ZIP — скачайте свежий ZIP, замените файлы в той же папке
и так же нажмите «Обновить».

## Если Chrome ругается

При каждом запуске Chrome может показывать «Отключить расширения в режиме
разработчика». Это обычное предупреждение для расширений, поставленных не из
магазина, — просто закройте его.
